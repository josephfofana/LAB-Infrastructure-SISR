# 10 – Bilan

## LAB-Infrastructure-SISR — UniService

## 1. Présentation

Cette section présente le bilan du laboratoire UniService.

L'objectif est de faire le point sur les compétences acquises, les configurations réalisées et les difficultés rencontrées au cours du projet.

---

## 2. Infrastructure réalisée

Le bilan portera notamment sur :

* L'infrastructure Windows Server
* Active Directory
* DNS
* DHCP
* Les postes clients
* Le serveur Linux
* Le réseau
* La sécurité
* La supervision

---

## 3. Compétences développées

Le projet permet de développer des compétences dans :

* L'administration Windows Server
* L'administration Linux
* Active Directory
* Les réseaux
* DHCP et DNS
* La gestion des utilisateurs et des droits
* La sécurité des systèmes
* La supervision
* Le diagnostic et le dépannage

---

## 4. Difficultés rencontrées

Les problèmes rencontrés au cours du projet seront documentés avec :

* Le problème rencontré
* La cause identifiée
* Les recherches effectuées
* La solution appliquée
* Le résultat obtenu
* Les connaissances acquises

---

## 5. Tests et validation

Les différents services seront validés à travers les tests réalisés dans le laboratoire.

Les résultats permettront de déterminer :

* Les éléments fonctionnels
* Les éléments restant à améliorer
* Les problèmes résolus
* Les limites actuelles de l'infrastructure

---

## 6. Améliorations possibles

Le laboratoire pourra être progressivement amélioré avec :

* Un second contrôleur de domaine
* Une segmentation réseau
* Un pare-feu
* Une solution de supervision
* Une sauvegarde centralisée
* Une automatisation PowerShell
* Une automatisation Python
* Des mécanismes de sécurité supplémentaires
