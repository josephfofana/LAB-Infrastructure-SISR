# 08 – Automatisation

## LAB-Infrastructure-SISR — UniService

## 1. Automatisation de l'infrastructure

Cette section présente les techniques d'automatisation utilisées dans le laboratoire UniService.

L'objectif est de réduire les tâches répétitives, fiabiliser les opérations d'administration et améliorer l'efficacité de la gestion de l'infrastructure.

---

## 2. PowerShell

PowerShell sera utilisé pour automatiser certaines tâches d'administration Windows.

Les sujets étudiés comprennent :

* Gestion des utilisateurs
* Gestion des groupes
* Gestion des services
* Informations système
* Administration Active Directory
* Vérification de la configuration
* Automatisation des tâches répétitives

---

## 3. Bash

Bash pourra être utilisé pour automatiser certaines tâches sur le serveur Linux.

Les sujets étudiés comprennent :

* Gestion des fichiers
* Gestion des utilisateurs
* Gestion des permissions
* Gestion des services
* Vérification du système
* Exécution de commandes automatisées

---

## 4. Python

Python pourra être utilisé pour développer des scripts permettant d'automatiser certaines opérations.

Les sujets étudiés pourront inclure :

* Manipulation de fichiers
* Traitement de données
* Automatisation de tâches
* Interaction avec le système
* Création de scripts d'administration

---

## 5. Automatisation de l'administration

L'automatisation pourra être appliquée à différentes tâches du laboratoire :

* Création de comptes
* Gestion des groupes
* Vérification des services
* Collecte d'informations système
* Contrôle de l'état des machines
* Génération de rapports
* Vérifications automatisées

---

## 6. Tests

Les scripts développés seront testés afin de vérifier :

* Leur fonctionnement
* Leur fiabilité
* Leur comportement en cas d'erreur
* Leur impact sur le système
* La possibilité de réutiliser les scripts
