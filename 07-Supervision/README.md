# 07 – Supervision

## LAB-Infrastructure-SISR — UniService

## 1. Supervision de l'infrastructure

Cette section présente la supervision des différents éléments de l'infrastructure UniService.

L'objectif est de pouvoir vérifier l'état des systèmes et détecter rapidement les anomalies.

---

## 2. Éléments supervisés

La supervision pourra porter sur :

* Les serveurs Windows
* Le serveur Linux
* Les postes clients
* Les services réseau
* Les ressources système
* La disponibilité des équipements

---

## 3. Ressources système

Les principales ressources surveillées sont :

* Processeur (CPU)
* Mémoire vive (RAM)
* Espace disque
* Utilisation réseau
* Processus
* Services actifs

---

## 4. Services

Une attention particulière sera portée à la disponibilité des services nécessaires au fonctionnement de l'infrastructure :

* Active Directory
* DNS
* DHCP
* Services Windows
* Services Linux
* SSH
* Services réseau

---

## 5. Analyse des événements

Les journaux système pourront être utilisés afin d'identifier :

* Les erreurs
* Les avertissements
* Les connexions
* Les problèmes de services
* Les événements importants
* Les anomalies de fonctionnement

---

## 6. Tests

Des vérifications seront réalisées afin de contrôler :

* La disponibilité des serveurs
* Le fonctionnement des services
* L'utilisation des ressources
* La connectivité réseau
* La présence d'anomalies
