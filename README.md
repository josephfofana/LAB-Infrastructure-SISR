# LAB-Infrastructure-SISR

## Laboratoire d'infrastructure systèmes et réseaux — UniService

Projet personnel réalisé dans le cadre de mon parcours **BTS SIO SISR**, ayant pour objectif de concevoir, déployer, administrer et documenter une infrastructure informatique d'entreprise dans un environnement virtualisé.

Le projet s'appuie sur une entreprise fictive, **UniService**, afin de reproduire des problématiques rencontrées dans une infrastructure professionnelle.

---

## 🎯 Objectifs du projet

- Concevoir une infrastructure réseau cohérente
- Mettre en place des services d'infrastructure
- Administrer des systèmes Windows et Linux
- Centraliser l'authentification et l'administration
- Mettre en œuvre des mécanismes de sécurité
- Automatiser certaines tâches d'administration
- Tester et valider le fonctionnement de l'infrastructure
- Documenter les configurations et les procédures

---

## 🏢 Contexte

**UniService** est une PME fictive composée d'environ 20 utilisateurs répartis dans plusieurs services.

L'objectif est de construire une infrastructure permettant aux utilisateurs de travailler dans un environnement centralisé, sécurisé et administrable.

## 🧪 Méthodologie

Chaque partie du laboratoire est documentée selon une démarche :

**Conception → Installation → Configuration → Tests → Validation → Documentation**

L'objectif n'est pas seulement de faire fonctionner les services, mais également de comprendre leur rôle, leur configuration et les problèmes pouvant apparaître en environnement professionnel.
