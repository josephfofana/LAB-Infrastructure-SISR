# 09 – Tests

## LAB-Infrastructure-SISR — UniService

## 1. Validation de l'infrastructure

Cette section regroupe les tests réalisés sur l'infrastructure UniService.

L'objectif est de vérifier que les différents systèmes, services et configurations fonctionnent correctement.

---

## 2. Tests système

Les systèmes seront vérifiés afin de contrôler :

* Le démarrage des serveurs
* Les ressources disponibles
* Les services actifs
* Les configurations système
* Les journaux d'événements

---

## 3. Tests réseau

Les tests réseau permettront de vérifier :

* La connectivité entre les machines
* L'adressage IP
* Le fonctionnement du DHCP
* La résolution DNS
* Les communications entre les serveurs et les clients

---

## 4. Tests Active Directory

Les fonctionnalités du domaine seront vérifiées à travers :

* La connexion des utilisateurs
* L'appartenance au domaine
* Les groupes de sécurité
* Les OU
* L'application des GPO
* Les droits d'accès

---

## 5. Tests de sécurité

Les tests de sécurité permettront de vérifier :

* Les permissions
* Les droits utilisateurs
* Les restrictions appliquées
* Les services exposés
* Les configurations de sécurité

---

## 6. Tests de fonctionnement

Des scénarios seront réalisés afin de simuler différentes situations :

* Connexion d'un nouvel utilisateur
* Ajout d'un poste au domaine
* Modification des droits
* Indisponibilité d'un service
* Problème de résolution DNS
* Problème d'adressage IP
